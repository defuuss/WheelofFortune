📚 Forfeit source

The wheel reads entries directly from the active character card's embedded Character Lorebook / Character Book. This makes a wheel travel with the character card.

Official v1.3 format: metadata belongs in the Lorebook entry Comment/Title (or keys). The Content field contains only the full roleplay instruction.

[WHEEL] [id=truth_01] [weight=4] [min=1] [max=3] Truth question
[WHEEL] [id=secret_01] [weight=2] [min=2] [max=5] [cooldown=2] Reveal a secret
[WHEEL] [id=plot_01] [weight=1] [level=5] [once] Major plot event

Persistence: no persistence tag = stays on the wheel. [cooldown=N] = temporarily removed for N completed spins. [once] = permanently removed for the current chat after it wins.

Stable IDs: [id=...] is strongly recommended. Use a unique slug such as secret_01. It keeps one-shot/cooldown identity stable when you rename the visible title.

Supported metadata: [WHEEL], [id=...], [weight=3], [min=2], [max=4], [level=3], [cooldown=2], [once].
